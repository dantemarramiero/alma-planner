# Alma Planet – pacchetto brand

Logo, icone e regole UI per Alma Planet, l'intranet e il project management interno di Almacis.

Per usarlo con Claude Code:
1. Copia questa cartella nel repository del software (per esempio in `brand/alma-planet/`).
2. Aggiungi questa riga al `CLAUDE.md` principale del repository: `Segui sempre le regole in brand/alma-planet/CLAUDE.md`.
3. Importa `tokens.css` nell'entry point dell'app.

Contenuto: `CLAUDE.md` (regole), `tokens.css` (variabili), `logo/` (SVG e PNG), `app-icon/` (icone app e favicon), `Alma Planet Brand.html` (scheda visiva).

Nota: negli SVG del logo con scritta il testo usa il font Roboto. Per la stampa o per usi fuori dal browser conviene convertirlo in tracciati con Illustrator o Figma.
